柏拉图《巴门尼德篇》
​
我们从家乡克拉佐美奈来到雅典，在市场遇见了阿德曼托斯和格劳孔。阿德曼托斯握住我的手说：欢迎你，凯发卢斯。你在雅典，有什么要我们效劳的吗？
有的，我说，我正是为此而来，想请你帮一个忙。什么忙？他说。我想请你告诉我，你那位异母弟弟的名字，我一时记不起来了。上次从克拉佐美奈来时，他还只是个孩子。而那已经是很久以前的事。他父亲的名字，如果我没记错，是皮里兰佩斯？对，他说，我们的弟弟名叫安提丰。可是你问这个做什么？请让我介绍几位同乡，我说。

他们都爱好哲学，听说安提丰曾与一位叫毕多铎的人交好——那是芝诺的朋友。他还记得多年以前苏格拉底、芝诺和巴门尼德之间的一场谈话，毕多铎生前曾多次向他复述。

确实如此。那么，我们能听他讲讲吗？我问。再容易不过，他答道。他年轻时曾用心研习过这篇谈话，如今心思却在别处了——像他的祖父安提丰一样，把全副精神放在了马匹上。不过，既然这是你们的来意，我们就去找他吧。他住在梅利特，离这儿很近。于是我们一同去找他。他在家里，正把一副马勒交给铁匠去修整。等他打发完铁匠，两位兄弟说明了来意。

他认出我是上次来访的旧识，向我致意。我们请他复述那场对话，起初他颇不情愿，终究还是答应了。他说，毕多铎曾描述过巴门尼德与芝诺的模样：二人是在泛雅典娜大节期间来到雅典的。巴门尼德那时约莫六十五岁，头发全白了，仪态却很好；芝诺年近四十，身材修长，相貌俊美。他们下榻在城墙外陶匠区毕多铎的家里。苏格拉底那时还是个很年轻的青年，前去拜访，同去的还有许多人。

大家都想听芝诺的著作，那是趁这次来访头一次带到雅典的。芝诺亲自诵读，当时巴门尼德不在场；读到快要终了时，毕多铎进来了，同他一道进来的是巴门尼德和阿里斯托特勒——后来成为三十僭主之一的那位。

​
诵读完毕，苏格拉底请他把第一个论证的第一个命题再读一遍。读完之后，苏格拉底说：芝诺，你这话是什么意思？你的主张是不是：存在者若是多，它就必定既相似又不相似？而这是不可能的——因为相似者不能是不相似的，不相似者也不能是相似的？正是，芝诺说。那么，如果不相似者不能相似，相似者不能不相似，照你所说，存在者就不可能是多。

你所说的这一切，除了驳斥「多」的存在之外，还有别的目的吗？你论文的每一节，是不是都意在分别提供一条证据——你写了多少论证，就有多少条关于「多不存在」的证明？这是你的意思呢，还是我误解了你？不，芝诺说，你对我全篇的主旨理解得很对。苏格拉底说：巴门尼德，我看得出来，芝诺不但想在友情上与你一体，在著作上也要做你的第二个自我。

他把你说的话换个方式讲出来，却几乎要让我们相信那是什么新东西。你在诗里说「万物是一」，并为此提出了出色的证明；他则说「多不存在」，并为此举出压倒性的证据。你立「一」，他破「多」。你们就这样瞒过了世人，让大家以为你们各说各话，其实说的几乎是同一件事。这番手段，可不是我们多数人所能企及的。
​

是的，苏格拉底，芝诺说。

不过，你虽然像斯巴达的猎犬一样善于追踪，却还没有完全看出这篇著作真正的来意。它并不像你想的那样是件精心造作的东西；你说的那种用心，其实是碰巧。

实情是：我写这些东西，是为了保卫巴门尼德的论证，抵御那些取笑他的人——他们宣称，从「一」的断定里会推出许多荒唐而矛盾的结果。我的回答是冲着「多」的拥护者去的，而且加倍奉还。他们那个「存在者为多」的假设推演到底，只会比「存在者为一」的假设更加荒唐。当年我出于捍卫老师的热忱写下这本书，那时还年轻；后来书稿被人偷走，出版与否竟由不得我了。

不过，写作的动机并非长者的虚荣，而是少年的好胜。这一点你好像没有看出来，苏格拉底；至于别的方面，你的理解是很中肯的。我明白了，苏格拉底说，你的说明我完全接受。
​

不过请告诉我，芝诺：你是不是进一步认为，存在一个自在的「相似之相」，还有一个与之相反的「不相似之相」；你、我，以及我们称之为「多」的其他万物，都分有这两者？

分有相似者，就在那种程度和方式上成为相似；分有不相似者，就在那种程度上成为不相似；而分有两者者，就既相似又不相似？万物既然分有这对相反者，岂不既相似又不相似吗？

这有什么可惊异的呢？倘若有谁能证明，绝对的相似者会变成不相似，绝对的不相似者会变成相似，那在我看来才真是奇迹。可是芝诺，指出仅分有相似与不相似的事物兼有两者，并不稀奇。同样，若有人证明万物因分有「一」而是一，同时因分有「多」而是多，那也不足为奇。但若有人向我指明，绝对的「一」即是多，绝对的「多」即是一，我才真要惊异了。他要证明我是多，便会说我有右侧和左侧、正面和背面、上半身和下半身——我分有「多」，这是无法否认的；他要证明我是一，便会说我们在座的是七个人，而我是其中之一，分有「一」。

若有人指明木头、石头之类的东西既是多又是一，我们承认他指明了一与多在可见事物上的共存；可他并没有证明多即是一、一即是多——他说的不是怪论，而是老生常谈。

然而，倘若有谁把相似与不相似、一与多、静与动这类单纯的「相」分别出来，进而指明它们在自身之中也能结合与分离，那我才会大为惊异。
芝诺，你这部著作把这部分论证处理得很有锋芒；不过，倘若有谁在唯有理智才能把握的「相」本身之中，也找出了你在可见事物里揭示的同样的纠葛与缠绕，那才会令我惊叹得多。
​
苏格拉底说这些话的时候，毕多铎觉得巴门尼德和芝诺对论证的一步步推进并不十分以为然；但他们始终凝神细听，还不时相视而笑，仿佛在赞赏他。等苏格拉底说完，巴门尼德道出了他们的心意。苏格拉底啊，他说，我钦佩你探求哲学的志趣。那么请告诉我：把自在的「相」与分有「相」的事物区别开来，这是你自己作出的区分吗？你是不是认为，存在一个离开我们所拥有的相似而独立的「相似之相」？

我认为确有这样的「相」，苏格拉底说。巴门尼德接着问：那么，正义、美、善，以及这一类东西，你也为它们设立自在的「相」吗？是的，他说，我设立。

那么人呢？你是否也设立一个离开我们、离开一切凡人的「人之相」？火与水，也有它们的「相」吗？巴门尼德啊，我常常拿不定主意，不知该不该把它们算进去。

那么，苏格拉底，那些说出来恐怕惹人发笑的东西呢——比如头发、污泥、秽物，以及其他鄙陋琐屑之物，你也同样犹疑吗？它们也各有一个与我们接触到的实物相分离的「相」吗？

当然没有，苏格拉底说。这类可见之物，呈现在我们面前是什么样子，就是什么样子；倘若为它们也设立「相」，恐怕就荒谬了。
虽然如此，我有时也不免惶惑，觉得万物似乎无物不有「相」；可每当我站定这个立场，我又赶忙逃开——我怕跌进无底的荒唐深渊，就此沉沦。于是我又回到方才说的那些「相」上。

是的，苏格拉底，巴门尼德说，那是因为你还年轻。如果我没看错，总有一天哲学会把你抓得更紧，到那时你连最微贱的东西也不会轻看；而在你这样的年纪，还难免太在意世人的议论。

不过我想知道的是：有某些「相」，其余万物因分有它们而得名——相似者因分有「相似」而相似，大者因分有「大」而大，正义的与美的事物因分有「正义」与「美」而成为正义的、美的？正是。
​
那么，每一个个别事物分有的，是「相」的整体呢，还是「相」的一部分？分有可能还有别的方式吗？不可能有了，他说。那么你认为，整个「相」是一，同时又存在于众多事物的每一个之中？因为这样一来，同一个东西作为整体，同时存在于许多彼此分离的个体之中，它便与自身相分离了。不然，「相」也许像白昼一样：白昼是同一个，同时又在许多地方，却依然与自身连续。

苏格拉底，我佩服你这让「一」同时遍处多方的办法。你的意思是说：倘若我展开一张帆，盖住许多人，便是一个整体覆盖着多——是不是这个意思？我想是的。那么你说，是整张帆覆盖着每一个人呢，还是帆的一部分覆盖这个人、另一部分覆盖那个人？是后者。那么，苏格拉底，诸「相」本身岂不就是可分的了吗？

分有它们的事物，每个只分有「相」的一部分，而不是整个「相」存在于每一个事物之中？看来只好如此。那么，苏格拉底，你还愿意说，那唯一的「相」既是可分的，又仍然是一吗？当然不能。
